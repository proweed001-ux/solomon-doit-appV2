# Order DOIT Android Wrapper

Android WebView wrapper for the production Solomon Do It App 2 website.

- App name: `Order DOIT`
- Package: `com.solomon.doitapp2`
- Website: `https://solomon-doit-app-v2.vercel.app/`
- Web updates appear in the APK without rebuilding it.
- APK updates are only required when native Android behavior changes.

The GitHub Actions workflow renders the supplied Order DOIT icon, builds an installable debug APK, and uploads it as an artifact.
